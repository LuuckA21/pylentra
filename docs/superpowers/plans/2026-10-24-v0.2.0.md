# Pylentra 0.2.0 — Piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** nuovo aspetto in stile C (morbido) e quattro migliorie: impostazioni
per categoria, connessione rapida, import da `~/.ssh/config`, colori e icone per
connessione.

**Architecture:** il core (`crates/pylentra-core`) riceve i nuovi campi del
modello, il metodo `AuthMethod::Auto`, il parser di ssh_config, l'import
atomico e l'elenco dei known_hosts; `src-tauri` aggiunge quattro comandi
sottili. L'interfaccia rifà i token in `app.css`, aggiunge pochi componenti in
`ui/src/components/ui/` e moduli puri in `ui/src/lib/` (ognuno con il suo test
Vitest), poi riscrive barra laterale, area sessioni e impostazioni.

**Tech Stack:** come la 0.1 (Rust 2024, russh 0.64, ts-rs 12, Tauri 2,
Svelte 5, xterm.js 6, Vitest). Unica dipendenza nuova:
`@fontsource-variable/manrope`.

**Spec:** `docs/superpowers/specs/2026-10-24-v0.2.0-design.md`, da leggere
insieme a questo piano. I riferimenti `§n` sono sezioni della spec.

## Global Constraints

- Nessun nuovo crate Rust. Unico pacchetto npm nuovo: `@fontsource-variable/manrope` (in `dependencies` di `ui/package.json`).
- Ogni testo visibile passa da `t()`; ogni chiave nuova va in `ui/src/lib/i18n/en.ts` **e** `it.ts`.
- I binding TS si rigenerano con `cargo test -p pylentra-core` e si committano (`ui/src/lib/bindings/`); CI fallisce se non aggiornati.
- Prima di ogni commit, dalla radice: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `pnpm --dir ui lint`, `pnpm --dir ui check`, `pnpm --dir ui test`. Per `src-tauri` serve `mkdir -p ui/dist`.
- Il core non usa `unwrap`/`expect`/`panic` fuori dai test (lint in `lib.rs`).
- Nomi dei colori: `red`, `orange`, `amber`, `green`, `teal`, `blue`, `violet`, `gray`. Icone: `server`, `database`, `web`, `nas`, `raspberry`, `cloud`, `container`, `terminal`.
- Chiavi `localStorage`: `pylentra.recent`, `pylentra.sidebar.collapsed`, `pylentra.sidebar.groups`, `pylentra.settings.section`. Ogni accesso passa da `ui/src/lib/prefs.ts`.
- Scorciatoie: solo combinazioni Ctrl+Shift (o Ctrl+Tab); Ctrl+K resta alla shell.
- Contrasto minimo 4,5:1 per testo/superfici e coppie `--tag-*-fg`/`--tag-*-bg`, nei due temi.
- Commit con il trailer del repository (`Co-Authored-By` e `Claude-Session`), push solo su `claude/awesome-cannon-6elqn5`.

## Review Focus

1. **Server con `MaxAuthTries` basso (OpenSSH: 6) e agent con molte chiavi** — `Auto` deve arrivare alla password invece di essere disconnesso: salta le chiavi predefinite già offerte dall'agent (confronto con `<file>.pub`). Test in Task 8.
2. **`~/.ssh/config` scritto su Windows (CRLF, BOM UTF-8)** — si legge come quello Unix. Test in Task 12.
3. **IPv6 senza parentesi nella connessione rapida (`::1`, `luca@fe80::1`)** — è un host senza porta, non un errore. Test in Task 10.
4. **`localStorage` assente, pieno o con JSON corrotto** — l'app parte e usa i valori predefiniti. Test in Task 4.
5. **Alias ripetuto in più blocchi `Host`** — un solo candidato, con la regola del primo valore. Test in Task 12.
