# Pylentra 0.5.0 — Piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** schermo diviso: più sessioni nella stessa scheda, con divisioni
annidate fino a 4 parti, focus da tastiera e divisori trascinabili.

**Architecture:** un modulo puro `ui/src/lib/layout.ts` gestisce l'albero delle
divisioni e ne calcola i rettangoli. Lo store tiene le schede (albero + focus)
e una lista piatta di parti (`PaneState`, l'ex `TabState`). `TabView` disegna
le parti di una scheda in posizione assoluta, con chiave `paneId`, così
dividere o chiudere non ricrea mai un terminale; `TerminalTab` diventa
`TerminalPane`.

**Tech Stack:** Svelte 5, xterm.js 6, Vitest + Testing Library. Solo
interfaccia: nessuna modifica a Rust, ai binding o ai file salvati. Nessuna
dipendenza nuova.

**Spec:** `docs/superpowers/specs/2026-10-28-v0.5.0-design.md`, da leggere
insieme a questo piano. I riferimenti `§n` sono sezioni della spec.

## Global Constraints

- Nessuna dipendenza nuova; nessuna modifica in `crates/` o `src-tauri/` salvo la versione in `Cargo.toml`/`Cargo.lock` (Task 7).
- `MAX_PANES = 4`; `ratio` sempre in `[0.1, 0.9]`; minimo per parte trascinando 160×120 px; frecce sul divisore ±0.05, Invio e doppio clic 0.5.
- Scorciatoie: `Ctrl+Shift+D` → `splitRight` (`dir: "row"`), `Ctrl+Shift+E` → `splitDown` (`dir: "column"`), `Alt+←/→/↑/↓` senza altri modificatori → `focusLeft/Right/Up/Down`, `Ctrl+Shift+W` chiude la parte col focus. Alt+lettera e Ctrl+Alt+freccia restano alla shell.
- Le schede non attive restano montate e nascoste, come oggi; le scorciatoie di una parte valgono solo con scheda visibile e parte col focus.
- Ogni testo visibile passa da `t()`; ogni chiave nuova va in `ui/src/lib/i18n/en.ts` **e** `it.ts`.
- Prima di ogni commit: `pnpm --dir ui lint`, `pnpm --dir ui check`, `pnpm --dir ui test`; prima del push anche `cargo fmt --all --check` e `cargo test --workspace` (con `mkdir -p ui/dist` e `CARGO_INCREMENTAL=0`).
- Commit con il trailer del repository; push solo su `claude/awesome-cannon-6elqn5`.

## Review Focus

1. **Chiudere una parte mentre `session_open` non ha ancora risposto** — la sessione va chiusa appena arriva l'id, come fa oggi `closeTab`. Test in Task 3.
2. **Scorciatoie su una scheda nascosta** — `Ctrl+Shift+D` o `Alt+→` agiscono solo sulla scheda attiva, mai sulle parti di una scheda nascosta. Test in Task 4 e 5.
3. **Chiudere la parte col focus in una scheda di 3** — il focus va alla prima parte del fratello e quel terminale riceve il focus della tastiera. Test in Task 5.
4. **Scheda nascosta o finestra larga 0 durante il calcolo del minimo** — `clampRatio` con `totalPx` 0 non produce `NaN` e resta in `[0.1, 0.9]`. Test in Task 6.
5. **Dividere una parte che mostra un prompt (password, chiave host)** — il prompt resta nella parte di origine e la nuova parte si connette per conto suo. Test in Task 4.

### Task 1: Albero delle divisioni (`layout.ts`)

**Files:**
- Create: `ui/src/lib/layout.ts`
- Test: `ui/src/lib/layout.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export type Dir = "row" | "column"; // row: a a sinistra, b a destra; column: a sopra
  export type Node = { pane: string } | { dir: Dir; ratio: number; a: Node; b: Node };
  export type Side = "left" | "right" | "up" | "down";
  export type Path = ("a" | "b")[];
  export type Rect = { x: number; y: number; w: number; h: number }; // % della scheda
  export type Divider = { path: Path; dir: Dir; area: Rect; ratio: number };
  export const MAX_PANES = 4;
  export function split(root: Node, paneId: string, dir: Dir, newId: string): Node;
  export function remove(root: Node, paneId: string): Node | null;
  export function setRatio(root: Node, path: Path, ratio: number): Node;
  export function clampRatio(ratio: number, totalPx: number, minPx: number): number;
  export function rects(root: Node): { panes: Record<string, Rect>; dividers: Divider[] };
  export function neighbor(panes: Record<string, Rect>, paneId: string, side: Side): string | null;
  export function count(root: Node): number;
  export function firstPane(root: Node): string;
  ```
  Funzioni pure: restituiscono nodi nuovi, non modificano l'input.

- [ ] **Step 1: Test** in `layout.test.ts`:
  - `split({pane:"A"}, "A", "row", "B")` → `{dir:"row", ratio:0.5, a:{pane:"A"}, b:{pane:"B"}}`; dividere una foglia interna sostituisce solo quella.
  - `remove` di A in `A | (B / C)` → `B / C` (`{dir:"column", a:B, b:C}`); `remove` dell'unica foglia → `null`; id assente → albero uguale.
  - `rects` di `A | (B / C)` con ratio 0.5: A `{0,0,50,100}`, B `{50,0,50,50}`, C `{50,50,50,50}`; due divisori, con `path` `[]` e `["b"]`.
  - `neighbor` sullo stesso albero: C `left` → A; A `right` → B (B e C si sovrappongono uguale, vince il più in alto); B `down` → C; A `left` → `null`.
  - `setRatio(root, ["b"], 0.95)` → 0.9; `0.02` → 0.1.
  - `clampRatio(0.05, 1000, 160)` → 0.16; `clampRatio(0.5, 0, 160)` → 0.5; `clampRatio(0.95, 0, 160)` → 0.9 (Review Focus 4).
  - `count` di `A | (B / C)` → 3; `firstPane` → `"A"`.
- [ ] **Step 2: `pnpm --dir ui test`** → FAIL.
- [ ] **Step 3: Implementare.** `neighbor`: candidati sono le parti il cui bordo opposto coincide (tolleranza 0.01) col lato `side` della parte e che si sovrappongono sull'altro asse; vince la sovrapposizione più lunga, a parità `y` minore poi `x` minore. `clampRatio`: `max(0.1, min(0.9, ratio))`, poi se `totalPx > 0` anche `max(minPx/totalPx, min(1 - minPx/totalPx, r))`.
- [ ] **Step 4: `pnpm --dir ui test`** → PASS.
- [ ] **Step 5: Commit** `feat(ui): split layout tree`.
