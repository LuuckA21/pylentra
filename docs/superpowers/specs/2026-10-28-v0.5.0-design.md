# Pylentra 0.5.0 — Schermo diviso

- **Data:** 2026-10-28
- **Stato:** in revisione
- **Base:** 0.4.1 (`main` a 04ad96f)
- **Issue:** [#14](https://github.com/LuuckA21/pylentra/issues/14)

## 1. Obiettivo

Vedere e usare più sessioni affiancate nella stessa scheda, per esempio due o
più server di un cluster.

**Criteri di successo**

- Una scheda si divide in verticale o in orizzontale, e ogni parte si divide
  ancora, fino a 4 parti (per esempio una 2×2 con quattro server diversi).
- La nuova parte apre una connessione salvata o rapida scelta dal selettore di
  Quick connect; Esc annulla senza lasciare parti vuote.
- `Alt+frecce` sposta il focus tra le parti; un clic dà il focus.
- Trascinando il divisore le parti si ridimensionano e `htop` si ridisegna.
- Dividere, chiudere o ridimensionare non perde il contenuto né la sessione
  delle altre parti.
- Ogni parte tiene i suoi prompt, la sua riconnessione e la sua barra di stato.

**Fuori ambito:** "scrivi in tutte le parti" (issue a parte); ricordare il
layout alla riapertura; spostare una parte in un'altra scheda o trascinarla;
più di 4 parti; SFTP, tag, export/import (#11, #17, #15).

## 2. Decisioni

| Area | Scelta |
|---|---|
| Layout | albero di divisioni annidate per scheda, al massimo 4 parti |
| Nuova parte | selettore di Quick connect (salvate o `user@host`), Esc annulla |
| Barra di stato | una per parte, come oggi (con forward, snippet, overlay) |
| Dividere | `Ctrl+Shift+D` affiancata, `Ctrl+Shift+E` sopra/sotto, pulsanti nella barra di stato |
| Focus | `Alt+frecce`, clic; bordo d'accento sulla parte col focus |
| Chiudere | `Ctrl+Shift+W` chiude la parte; l'ultima parte chiude la scheda |
| Titolo scheda | nome della parte col focus, più "+N" |
| Broadcast | rimandato, nuova issue |
| Persistenza | nessuna: il layout non si ricorda alla riapertura |

Solo interfaccia: nessuna modifica a Rust, ai binding ts-rs o ai file salvati.
Nessuna dipendenza nuova.

## 3. Modello (`ui/src/lib/layout.ts`, nuovo)

```ts
type Dir = "row" | "column"; // row: affiancate (a sinistra a, a destra b)
type Node = { pane: string } | { dir: Dir; ratio: number; a: Node; b: Node };
type Rect = { x: number; y: number; w: number; h: number }; // in % della scheda
```

Funzioni pure:

- `split(root, paneId, dir, newId)`: la foglia `paneId` diventa
  `{ dir, ratio: 0.5, a: paneId, b: newId }`.
- `remove(root, paneId)`: il fratello della foglia ne prende il posto; `null` se
  era l'unica.
- `setRatio(root, path, ratio)`: `path` è la sequenza `"a" | "b"` dalla radice
  al nodo di divisione; il valore è limitato a `[0.1, 0.9]`.
- `clampRatio(ratio, totalPx, minPx)`: limita anche perché entrambe le parti
  restino di almeno `minPx`.
- `rects(root)`: `paneId → Rect` e l'elenco dei divisori
  `{ path, dir, rect }`.
- `neighbor(rects, paneId, side)`: tra le parti che toccano il lato `side` della
  parte, quella con la sovrapposizione più lunga; a parità la più in alto o la
  più a sinistra; `null` se non ce n'è.
- `count(root)` e `MAX_PANES = 4`.

## 4. Stato (`ui/src/lib/sessionReducer.ts`, `stores/sessions.svelte.ts`)

- `TabState` diventa `PaneState`: stesso contenuto, `tabId` → `paneId`.
  `reduce` e `initialTab` (→ `initialPane`) invariati nella logica.
- Lo store diventa:

  ```ts
  sessions = {
    tabs: { tabId: string; root: Node; focus: string }[],
    panes: PaneState[],
    active: string | null, // tabId
  }
  ```

- `connect`, `write`, `answer`, `linkQuickTab` (→ `linkQuickPane`) lavorano per
  `paneId`, con la stessa logica di oggi (la coda delle scritture resta per
  sessione).
- `openTab(connectionId)` e `openQuickTab(target)` creano una scheda con una
  parte; restituiscono il `paneId`.
- Nuove: `splitPane(paneId, dir, target)` (target: id di una connessione
  salvata o `QuickTarget`; rifiuta oltre `MAX_PANES`; il focus va alla nuova),
  `closePane(paneId)` (chiude la sessione se viva, toglie la foglia, il focus va
  alla prima foglia del fratello; l'ultima parte chiude la scheda),
  `focusPane(paneId)`, `moveFocus(side)` (sulla scheda attiva, con `neighbor`).
- `closeTab(tabId)` chiude tutte le parti della scheda.
- `cycleTab` invariata.

## 5. Componenti

- **`TerminalTab.svelte` → `TerminalPane.svelte`:** riceve `pane`, `visible`
  (scheda attiva) e `focused`. Le scorciatoie della parte valgono solo con
  `visible && focused`; il fit al cambio d'area c'è già (`ResizeObserver`).
  Un clic (o il focus del terminale) chiama `focusPane`. La barra di stato
  aggiunge due pulsanti "Dividi affiancata" e "Dividi sotto", disattivati con
  4 parti. Bordo d'accento se `focused` e la scheda ha più di una parte.
- **`TabView.svelte` (nuovo):** per una scheda disegna le parti in una lista
  piatta con chiave `paneId`, ognuna in posizione assoluta nel suo `Rect`, così
  una divisione o una chiusura sposta le parti senza ricrearle (il terminale e
  la sessione restano). Sopra disegna i divisori:
  - trascinabili col puntatore (pointer capture), con un minimo per parte di
    160×120 px (circa 20 colonne e 5 righe più la barra di stato col carattere
    di default);
  - doppio clic: `ratio` 0.5;
  - da tastiera: `role="separator"`, `aria-orientation`, `aria-valuenow` in
    percentuale, frecce ±5%, Invio 50%.
- **`SplitPicker.svelte` (nuovo):** dialogo modale con dentro `QuickConnect`;
  la scelta chiama `splitPane`, Esc o un clic fuori chiudono senza dividere. Si
  chiude da solo se la scheda o la parte da dividere spariscono.
- **`App.svelte`:** una `TabView` per scheda (le schede non attive restano
  montate e nascoste, come oggi); titolo della scheda dalla parte col focus,
  più "+N"; `openConnectionIds` e il conteggio delle sessioni vive su tutte le
  parti; la × della scheda chiede una sola conferma per tutte le sue sessioni
  vive.

## 6. Scorciatoie (`ui/src/lib/shortcuts.ts`)

| Tasti | Azione |
|---|---|
| `Ctrl+Shift+D` | `splitRight`: divide la parte col focus, nuova a destra |
| `Ctrl+Shift+E` | `splitDown`: divide la parte col focus, nuova sotto |
| `Alt+←/→/↑/↓` | `focusLeft/Right/Up/Down` |
| `Ctrl+Shift+W` | `closeTab` diventa "chiudi la parte col focus" |

Alt con altri tasti, e Ctrl+Alt+frecce, passano alla shell come oggi. Le
scorciatoie esistenti restano. `fromOtherModal` invariato: un dialogo in una
parte blocca le scorciatoie di finestra solo per i tasti che partono da lì.

## 7. Casi limite

- **Sessione finita:** la parte resta con "Session ended. Press Enter to
  reconnect." e la sua riconnessione automatica; non si chiude da sola.
- **Prompt in più parti:** ognuna mostra il suo; quello di una parte senza focus
  si vede e si usa con un clic.
- **Chiusure:** una parte viva chiede conferma se `confirm_close_active`; la ×
  della scheda chiede una volta ("Chiudere 3 sessioni attive?"); la chiusura
  della finestra conta tutte le parti.
- **Finestra più piccola:** i `ratio` restano; il minimo vale solo trascinando.
- **Quick connect in una parte:** "Salva connessione" collega solo quella parte.
- **Recenti e pallini della barra laterale:** per ogni parte arrivata a Ready.
